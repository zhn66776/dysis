# AgentDesk · The Living Office

本地、无顶、可俯看的三维像素办公室。当前提供完整的交互演示和可替换的 Agent/portfolio 桥接接口，没有接入官方账户或实际投资数据，不发起模型回合。

## 打开

在项目根目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory web-prototype
```

访问 http://127.0.0.1:4173/。代码和素材均从本地加载，浏览器需要 WebGL 2。

## 空间与操作

- 默认从固定俯视角查看完整办公室；窗口尺寸变化时场景自适应，点击伙伴或房间标签触发互动。
- Claude、Codex、Grok、Gemini 四位像素伙伴待机时坐在各自工位。角色列表可由宿主提供 1–5 位有效 Provider 伙伴。
- 点击人偶、工位或下方伙伴名，会邀请该伙伴沿通道进入你的玻璃办公室。你坐在自己的办公桌后，伙伴坐到访客椅上。
- 在底部输入消息，伙伴会在办公室中工作。回复结束后闲置 60 秒，伙伴会自动走回自己的工位；继续输入会重置倒计时，工作中暂停计时。回桌后再次发送会重新邀请。
- 点击沙发或“一起聊聊”，所有伙伴和你会走到讨论区。可勾选部分伙伴留下，其余人回桌。群聊按发言者分别显示，至少选择两位伙伴。
- “结束讨论”让所有伙伴和你返回各自座位。关闭侧边面板只隐藏面板。
- 点击办公室里的 Portfolio 屏幕或顶部“投资组合”，打开只读持仓面板。未接入时显示空值，不填入虚构收益。
- 自动光照使用电脑的本地时间和时区，在清晨、上午、中午、下午、黄昏、夜晚之间连续变化。也可手动预览。窗外包含三维树木、建筑、日月、云和夜间灯光。

光照按照本地时钟变化，不使用地理定位计算天文日出日落。角色、私聊与群聊历史保存在页面内存中，刷新会重置。

## 结构

- `app.js`：邀请、私聊、讨论组、闲置返回、面板与光照控制。
- `scene.js`：三维相机、人偶移动、场景拾取、状态与标签。
- `nordic-room.js`：房间、玻璃办公室、分组工位、讨论区和寻路障碍。
- `voxel-assets.js`：原创像素人偶、简化家具、坐下/行走/工作姿态。
- `daylight.js`：按本地时间变化的天空、室外场景与照明。
- `navigation.js`：绕过桌子和隔墙的通道寻路。
- `bridge.js`：本地演示实现与可注入的真实数据适配器。
- `session-utils.js`：可取消回复与 60 秒闲置计时。
- [API.md](API.md)：接入方式、数据结构和事件。

设计参考：
- [Muuto HQ / Danielsen Spaceplanning](https://danielsen.eu/en/project/muuto-hq/)：不同工作方式的分区与共享空间。
- [AM Office / Pernille Lind Studio](https://www.pernillelindstudio.co/projects/am-office/)：木色、柔和织物、私密办公室与非正式会谈区域。

当前像素几何和纹理为本项目原创，不使用参考项目的照片作为场景素材。本次仅更新网页原型，原生 macOS 应用保持独立。
